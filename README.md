# buckleberry

Buckleberry is a simple service that exposes content from several common self-hosting services via an Open Publishing Distribution System (OPDS) interface.

## Running

Buckleberry comes with a Dockerfile that can be used to run the app. If you'd like to run it manually, the makefile provides a `run` command.

On first launch, open the server in a browser and complete onboarding. You'll set your admin login and configure at least one content source (Wallabag, Linkding, or both). Password confirmation is required.

## Configuration

Set via environment variables or a `.env` file:

| Variable        | Default                  | Description                                        |
| --------------- | ------------------------ | -------------------------------------------------- |
| `PORT`          | `8080`                   | Port to listen on.                                 |
| `BASE_URL`      | `http://localhost:$PORT` | Public URL, used to build OPDS feed links.         |
| `DB_PATH`       | `./buckleberry.db`       | SQLite database path.                              |

## Deployment

The `Dockerfile` builds a static, CGO-free binary onto `distroless/static`.
 
For [Coolify](https://coolify.io/):

1. Point a new resource at this repo; it builds the `Dockerfile` automatically.
2. Add a **persistent volume mounted at `/data`** — the SQLite DB lives there and would otherwise reset on redeploy.
3. Set env vars:
   - `BASE_URL` → your public URL (e.g. `https://buckleberry.example.com`). Required — OPDS links are built from it.

## Development

Buckleberry runs on a very simple and self-contained tech stack. The core app is built using Golang and the Fiber web framework. All the views are built with Templ, which is so good I started writing all of my web apps in Go. Front-end interactivity is very limited, but what's there is built with Alpine.js and HTMX.

Templ templates must be compiled into Go. The makefile has two commands to do this - `make generate` for one-time generation and `make watch` to spin up a server that recompiles the templates whenever they're changed.

Your editor will probably need Templ on your path, and you may also need to install it locally as a Go tool:

```sh
go install github.com/a-h/templ/cmd/templ@v0.3.1020
go get -tool github.com/a-h/templ/cmd/templ
```
